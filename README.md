# UniLink

A monorepo with two workspaces:

```
unilink/
├── client/   # React + Vite frontend (to be built)
└── server/   # Supabase backend (to be set up)
```

## client/

This directory will hold a React + Vite application. It is currently a placeholder.

## server/

This directory will hold a Supabase project (database, auth, edge functions, etc.).
